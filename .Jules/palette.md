## 2024-08-13 - Added contextual ARIA labels to list action buttons\n**Learning:** In Angular/Ionic lists (like `ion-item` loops), action buttons (e.g., 'Delete', 'Forget', 'Remove') need dynamic `[attr.aria-label]` attributes. Without them, screen readers announce repeated generic labels, making it impossible to know which list item the action applies to.\n**Action:** When adding actions to list rows, always include an `[attr.aria-label]` that dynamically interpolates the row's name or title to provide context (e.g., `[attr.aria-label]="'Delete ' + item.name"`).
